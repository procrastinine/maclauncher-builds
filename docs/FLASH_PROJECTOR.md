# Adobe Flash Player projector

MacLauncher Builds provides the supplied Adobe Animate Flash Player 35.0.0.60 application for ARM64 and Intel Macs running macOS 11 or later. This is a prebuilt, closed-source application. MacLauncher does not compile or patch its executable or resources.

Package metadata uses the publisher version, `35.0.0.60`. The older `35.0.0.60-MCLv1` record remains readable for existing installations. Both packages retain all 74 files in the supplied app bundle, including their contents, permissions and signatures. Only the package inventory and runtime manifest outside the app carry the package identity.

The supplied app has an ad-hoc code signature, with no Developer ID certificate or Team ID. Its signature checks the bundle's internal consistency and does not authenticate a publisher. The package catalog records the archive's SHA-256, and the inventory records the files inside it. The [input descriptor](../producers/flash-projector/publisher-input.json) lists the original package download and the size, SHA-256 and permissions of every supplied app file.

The [package format](PACKAGES.md#package-tools) describes these inventories. [Verifying MacLauncher Builds](../VERIFYING.md#files-from-other-publishers) explains checks for finished software from other publishers.
