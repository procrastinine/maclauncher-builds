# MacLauncher Builds

MacLauncher Builds is a companion repository for MacLauncher. It holds the runtime source pins, owned adaptations and build recipes used by the launcher, with package support defined by MacLauncher's runtime requirements.

Each runtime has its own binary-only release. Release tags identify the corresponding source, patches and pinned dependencies. Installation and version selection are handled through MacLauncher; installed runtimes remain available offline.

The [main MacLauncher repository](https://github.com/procrastinine/maclauncher) describes app features and usage. The [package reference](docs/PACKAGES.md) and [release reference](docs/RELEASES.md) cover this repository’s technical interfaces.
